# 招聘与入职 SOP（版本 V1.8，生效日期 2025-09-01）

## 第 1 条 入职流程（状态机）
1.1 标准节点依次为：offer 确认 → 材料收集 → 主管审批 → HR 复核 → IT 开账号 → 工位与门禁 → 入职引导 → 完成。
1.2 材料清单：身份证、学历证明、离职证明、银行卡、体检报告、1 寸照片。
1.3 主管审批节点必须人工确认，Agent 不得自动代批（Human-in-the-loop 强制节点）。
1.4 IT 开账号由 ITSM 系统自动执行，需记录工单号；失败时流程暂停并通知 IT 值班，不得跳节点。
1.5 全流程目标时效 2 个工作日，超过 1 个工作日未推进，系统向 HRBP 发送超时提醒。

## 第 2 条 试用期
2.1 劳动合同期限 3 年及以上的，试用期不超过 6 个月；1–3 年的不超过 2 个月。
2.2 试用期辞退须满足「不符合录用条件」：有明确的岗位录用条件告知书、有考核记录、有面谈纪要，三者缺一不可。
2.3 试用期辞退流程：主管发起 → HRBP 合规审查 → 法务会签 → 总经理审批 → 出具解除通知 → 办理离职交接。
2.4 仅以「感觉不合适」为由辞退，属于高风险违规操作，HRBP 应驳回。

## 第 3 条 转正
3.1 试用期届满前 15 天，系统自动触发转正评估，由直属主管提交评估表。
3.2 评估维度：岗位胜任度、协作表现、目标达成、价值观，各占 25%。
3.3 转正生效日为试用期届满次日，薪资调整自生效日起计算。

## 第 4 条 离职
4.1 正式员工提前 30 天书面通知，试用期提前 3 天。
4.2 离职交接清单包含：资产归还、账号注销、知识文档移交、项目交接人确认、财务借款结清。
4.3 账号注销须在离职生效日当天完成，逾期按信息安全事件上报。
