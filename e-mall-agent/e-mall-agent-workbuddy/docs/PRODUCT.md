# 产品功能说明

## 1. 产品定位

面向电商运营与客服团队的智能体工作台：用户用自然语言完成商品咨询、下单、订单查询、退款与政策问答；运营/客服在后台查看智能体的决策链路、工具调用、权限审计与工作流状态。

## 2. 目标用户与权限

| 角色 | 典型用户 | 能力 |
|---|---|---|
| 访客 guest | 未登录用户 | 商品浏览/搜索、政策问答；不能查订单、下单、退款 |
| 客户 customer | 消费者 | 访客能力 + 自己的订单查询、下单、退款申请 |
| 客服 service | 售后客服 | 跨客户订单查询与退款处理、查看 Trace 与审计日志 |
| 管理员 admin | 系统管理员 | 全部权限，含工作流审批与用户管理预留权限 |

## 3. 功能清单

### 3.1 智能对话（核心）

- 自然语言多轮对话，SSE 逐段输出，界面实时展示：当前节点、意图路由、工具调用、最终回答。
- 四类 specialist：
  - **商品导购**：按关键词/需求搜索商品，返回真实 id、名称、价格、库存；可查询单个商品与库存。
  - **订单专员**：查询我的订单、按订单号查状态、基于真实库存下单。
  - **售后专员**：知识库政策问答、按订单号发起退款（校验归属与权限）。
  - **通用客服**：一般问答与知识库兜底。
- 快捷提问按钮与"上下文工程"侧栏：可见每次对话注入了哪些知识、工具清单、字符预算、历史压缩情况。

### 3.2 商品与订单

- 商品搜索（名称/品类/标签/描述）、库存状态展示。
- 订单列表（按角色隔离）、订单详情、创建订单（库存校验）、退款申请。
- 前端商品卡可一键把商品问题带入对话。

### 3.3 工作流与人工审批

- 订单履约工作流：订单校验 → 库存复核 → 锁定库存 → 大额人工审批 → 生成发货单 → 履约完成。
- 金额 ≥ ¥500 触发人工审批中断；管理员可批准或拒绝；拒绝则订单取消。
- 前端以 SVG 图展示节点/分支，并展示每次运行的步骤时间线与中断详情。

### 3.4 可观测与治理

- Trace：节点流转、工具名/参数/结果摘要、最终答案长度，可按 trace_id 过滤。
- Audit：登录成功/失败、下单、退款、越权访问、审批决策。
- 权限矩阵与角色切换：一键用不同角色登录，直观验证越权拦截。
- RAG 检索面板：直接查看政策知识命中结果。
- Metrics：Counter/Gauge/Histogram，展示任务成功率、工具错误率、Token 总量与 P95/P99 延迟。
- 评测体系：Golden Case 批量评测、Trace Replay 复现 Bad Case、回归门禁阻止质量退化。

### 3.5 能力实验室

侧栏新增"能力实验室"页，把 Agent 工程的底层能力以可交互方式暴露，输入与输出实时可见：

| 能力 | 用户可见内容 |
|---|---|
| 规划与推理 | 切换 ReAct / Plan-and-Solve，输入目标后展示答案与逐步执行轨迹、终止原因 |
| 混合检索 | 切换 hybrid/bm25/vector，展示召回结果、RRF 分数与双通道来源明细 |
| 三层记忆 | 按 thread_id 召回，展示工作记忆轮数、情景条数、用户摘要与可注入上下文、token 估算 |
| 代码沙箱 | 运行 Python 片段或 Code Mode 工具编排，展示 stdout、返回值、错误与耗时 |

### 3.6 进阶知识治理（API 层）

- 文档解析与三种切片策略（固定+overlap / 章节 / 语义段落）。
- 知识版本管理、增量索引、撤销/回滚、租户与分类隔离。
- 引用质量校验与 groundedness 评分，列出答案中未被召回证据支撑的句子。
- Text2SQL（受限 SELECT，防注入）与 Text2Cypher（可执行 Cypher 模板）、GraphRAG 1-2 跳图谱检索。
- 可靠性一站式包装：幂等键、超时、指数退避重试、多级降级、终止条件。
- 长任务 Checkpoint：中断后按 task_id 从断点恢复，幂等步骤不重复。

## 4. 典型用户旅程

1. 张三点"快捷提问：推荐降噪耳机" → 路由到商品导购 → 调用 `search_products` → 返回 P001 ¥899 库存 12。
2. 张三问"我的订单" → 订单 Agent 调用 `list_orders`，只返回 U001 的两笔订单。
3. 张三问"O1001 怎么退款" → 售后 Agent 校验归属 → `initiate_refund` → 状态变为 `refund_requested`，审计落库。
4. 管理员打开工作流页，运行 O1001 → 因 ¥1098 触发审批中断 → 点击"批准" → 订单变为 `shipped`，履约完成。
5. 客服登录后在管理页查看 Trace 与 Audit，确认每一步工具调用与权限决策。

## 6. 非目标与限制

- 演示数据存于内存，服务重启后恢复种子状态。
- 默认离线规则模型用于确定性与零成本演示；复杂语义理解需切换 OpenAI 兼容模型。
- 库存/订单为简化领域模型，未接入真实支付、物流与库存中心。
- Token 为轻量 HMAC 实现，生产应使用企业 IdP 并增加限流、幂等与 CSAF 合规审计。
