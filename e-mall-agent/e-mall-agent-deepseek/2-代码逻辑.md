> 节点名取自真实符号；行尾中文注释放最后，不挤左侧列

## 1. chat/stream 核心方法汇总

```
  body {sessionId, clientMsgId}
        |
        | StreamReq(alias=...) + populate_by_name=True
        v
  POST /chat/stream   ----->  @router.post("/stream")
        |
        v
  stream(req, request, user=Depends(get_current_user))
        |
        +-----> session_memory.get_session(req.session_id, user.id)     # 归属校验, 失败 404
        +-----> limit_chat(user.id, req.session_id)                     # Redis 限流
        +-----> new_trace_id()                          -----> trace_id
        +-----> _claim_client_msg(session_id, client_msg_id) -----> duplicate
        +-----> runs.start(req.session_id)                             # _flags[sid] = False
        |
        v
  StreamingResponse(event_stream(), "text/event-stream")
        |
        | Cache-Control: no-cache, no-transform
        | Connection: keep-alive
        | X-Accel-Buffering: no       <-- 禁 nginx 缓冲, SSE 命门
        v
  event_stream()   [async generator, 客户端拉流时才真正执行]
```

## 箭头汇总

```
----->   ---->   -->   ->     正向调用，横杠越多越好对齐（推荐 5 个）
<-----   <----                回指、被谁调、补偿/重试入口
<----->                      双向依赖
 |    v    V    ↓             竖向：| 走线，v 落点；↓ 单字符但中文环境易错位
 +----+----+                  分叉 / 汇合的十字
 ····>   - - ->   ....>      断边：反射 / AOP / 装饰器 / getattr / HTTP / MQ
 =====>                       主路径强调
 [xxx]   (xxx)   ★           节点 / 外部系统 / 当前聚焦方法
```

### 案例2. 竖向主链（`|` 是线，`v` 是箭头）

```
        OrderConfirm.vue : onConfirm
                  |

                  v
        useOrderCart#submitOrder
                  |
                  | fetch('POST /api/order')     <-- 跨语言断点
                  v
        OrderController#create
                  |
                  v
        OrderService#placeOrder  <-------------  OrderRetryJob#retry
                  |
        +---------+----------+----------+
        |         |          |          |
        v         v          v          v
  InventoryClient  OrderRepo  MapStruct  publishEvent
    #deduct        #save      #toVO        |
                                           | @EventListener（AOP 断边）
                                           v
                                     OrderPaidListener
```
