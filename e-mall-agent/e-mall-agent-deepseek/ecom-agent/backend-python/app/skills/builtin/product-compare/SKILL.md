# 商品对比 Skill

## 何时启用

用户提出选购/比价/二选一需求：例如"5000 以内拍照手机推荐"、
"小米 15 和 iPhone 16 哪个好"、"这两款耳机对比一下"。

## 执行步骤

1. **抽取约束**：预算（min/max）、品牌、品类、关键参数（影像/续航/重量/芯片）、
   使用场景（拍照、游戏、办公）。缺关键约束且无法推断时，最多追问 1 个问题。
2. **召回候选**：调用 `search_products`（带 `maxPrice` / `brands` / `topK`）；
   候选不足时放宽预算或补充同义词再检一次，不要重复相同参数。
3. **补详情**：对前 3 个候选调用 `get_product_detail` 获取参数与库存。
4. **结构化对比**：候选 ≥2 时调用 `compare_products`，按统一维度输出。
5. **给结论**：先给 1 句推荐结论，再给对比表，再给"适合谁 / 不适合谁"。

## 对比维度（按品类裁剪，不要全部堆砌）

| 维度 | 说明 |
|---|---|
| 价格 | 到手价 + 是否在预算内 + 与同档位价差 |
| 核心参数 | 手机：影像/续航/芯片；耳机：降噪/续航/佩戴；笔记本：性能/重量/屏幕 |
| 口碑 | 评分、销量（来自工具返回，不要编造） |
| 库存/时效 | 有货状态，缺货时给出替代款 |
| 风险点 | 明显短板（如重量、无充电器、仅线上保修） |

## 回答模板

> 结论：在 {预算} 内，{推荐款} 更适合 {场景}，因为 {1-2 个核心理由}。
>
> | 维度 | A | B | C |
> |---|---|---|---|
> | 价格 | … | … | … |
>
> 更适合你：…；如果更在意 …，可以选 …。

## 禁止事项

- 不要虚构不存在的型号、价格、评分或"官方补贴"；
- 不要只罗列参数而不给结论，也不要把召回结果原样贴给用户；
- 不要贬低竞品或使用绝对化用语（"最好""第一"）；
- 商品参数以工具返回为准，工具缺失时明确说明"暂未获取到"。

## 引用要求

涉及价格/库存/参数的结论需来自 `search_products` / `get_product_detail` / `compare_products`；
涉及平台规则（价保、以旧换新）时另附知识库引用。
