## 3. 命名与代码规范

### Python
- 目录：`app/{api,agents,llm,rag,tools,memory,hitl,security,obs,infra,eval,common}`
- 命名：模块 `snake_case`，类 `PascalCase`，常量 `UPPER`，Pydantic 模型后缀 `Req/Resp/VO`
- 异步优先：所有 IO 用 `async def`
- 类型注解必须完整；公共函数写 docstring

### Java
- 包根：`com.xingtu.agent`
- 分层：`api(controller/dto)` / `service` / `agent` / `llm` / `rag` / `tool` / `infra` / `obs` / `security` / `eval`
- 类后缀：`Controller` `Service` `Repository` `Tool` `Model` `Properties`
- 依赖注入优先构造器注入；配置用 `@ConfigurationProperties`
- 统一返回 `ApiResponse<T>`，异常走 `@RestControllerAdvice`

### 前端
- 目录：`src/{api,views,components,stores,router,types,utils,styles}`
- 组合式 API `<script setup lang="ts">`
- 类型全部定义在 `src/types/`
- API 层统一 `src/api/*.ts`，不直接在组件里 fetch

## 4. 数据库访问约定

- 表名/字段名 `snake_case`，实体映射到驼峰
- 软删除只用 `knowledge_document.deleted_at`
- 所有时间字段用毫秒精度 `DATETIME(3)`，Java 侧 `LocalDateTime`
- JSON 字段：Python 侧 `json.loads`，Java 侧用 `String` + Jackson 手动序列化（避免 MyBatis TypeHandler 复杂度）
- 分页从 `page=1` 开始

## 5. Agent 设计约定（两端一致）

| Agent | 职责 | 工具集 |
|---|---|---|
| `SUPERVISOR` | 意图路由、任务分派、结果聚合 | 无（只路由） |
| `SHOPPING` | 商品导购、比价、对比推荐 | `search_products` `get_product_detail` `compare_products` `search_knowledge` |
| `SERVICE` | 订单、物流、售后、退款 | `get_order` `list_orders` `get_logistics` `check_refund_eligibility` `create_refund_request` `search_knowledge` `escalate_to_human` |
| `OPS` | 经营分析、报表 | `text2sql` `run_python` `search_knowledge` |

**工具风险分级**：
- `READ`：直接执行
- `WRITE`：执行 + 审计
- `IRREVERSIBLE`：**必须**先创建 `approval_task`，人工通过后才执行

**终止条件**（任一满足即停）：
1. 模型输出无 tool_call 的最终答案
2. `step >= MAX_STEPS`
3. `tokens >= MAX_TOKEN_BUDGET`
4. 耗时 >= `TASK_TIMEOUT_SECONDS`
5. 连续 2 步无新增信息（无进展检测）
6. 同一工具 + 同一参数连续调用 2 次（循环检测）
7. 触发 `IRREVERSIBLE` 工具 → 挂起等审批

## 6. 测试约定

- Python：`pytest` + `pytest-asyncio` + `httpx.AsyncClient`；测试目录 `tests/{unit,integration,e2e}`
- Java：`JUnit 5` + `Mockito` + `@SpringBootTest` + `MockMvc`；目录 `src/test/java/...`
- 前端：`vitest` + `@vue/test-utils`
- **测试必须默认使用 Mock LLM / hash embedding，不依赖外部 API**
