# 部署手册 · Docker Compose

## 一、一键启动

```bash
cp infra/.env.example infra/.env
# 填 DEEPSEEK_API_KEY / QWEN_API_KEY；不填则 LLM_MODE=mock 离线可跑
docker compose -f infra/docker-compose.yml up -d --build
bash infra/scripts/smoke.sh
```

| 服务 | 端口 | 说明 |
|---|---|---|
| frontend (nginx) | 8081 | Vue3 静态 + /api 反代 |
| backend-python | 8000 | FastAPI + LangChain 1.5.2 |
| backend-java | 8080 | Spring Boot 3 + LangChain4j 1.24.0 |
| mysql | 3306 | 会话/审批/幂等/轨迹/评测/知识元数据 |
| redis | 6379 | 会话 KV / 缓存 / 限流 |
| rabbitmq | 5672 / 15672 | longtask / audit / ragindex |
| milvus | 19530 | 向量库（etcd + minio 依赖） |
| etcd / minio | 2379 / 9000 | Milvus 依赖 |
| prometheus | 9090 | Metrics 抓取与查询 |
| otel-collector | 4317 / 4318 / 8889 | OTLP Trace 与 GenAI 属性 |
| etcd | 2379 | Milvus 元数据依赖 |
| minio | 9000 / 9001 | Milvus 对象存储依赖 |

> compose 共 **11 个 service**；前端反代用的是 `frontend/nginx.conf`，
> `infra/nginx/nginx.conf` 只是独立部署参考，compose 并不加载它。

## 二、配置校验（无需拉镜像）

```bash
docker compose -f infra/docker-compose.yml config -q
python3 scripts/verify_all.py
```

## 三、切换后端

前端构建时注入：
```bash
VITE_BACKEND=java npm run build     # 或 python
```
运行时也可由 nginx 的 `/api/py/*` `/api/java/*` 双路径同时保留，界面顶部显示当前后端。

## 四、切真实模型

```dotenv
LLM_MODE=real
DEFAULT_PROVIDER=deepseek
DEEPSEEK_API_KEY=sk-xxx
QWEN_API_KEY=sk-xxx
MODEL_VERSION_PIN=deepseek-chat-2026-11-18
```
`MODEL_VERSION_PIN` 会做启动校验：上游静默升级导致实际版本不一致时**阻断发布**（总纲 5.7 / C#12）。

## 五、数据初始化

`infra/mysql/init/01-schema.sql` 与 `02-seed.sql` 由 MySQL 容器首次启动自动执行。
Milvus 集合由后端 `ensure_collection()` 幂等创建（HNSW，dim=1024）。
RabbitMQ 交换机/队列由 `definitions.json` 预置，Java `AgentEvents` 也会声明式建。

## 六、灰度与回滚

1. `POST /v3/prompts/register` 注册 canary（默认 10% 流量）。
2. `POST /v3/evals/stability` 跑 pass^k；`python3 tests/ci/gate.py` 三重门禁。
3. `POST /v2/skills/invoke` 之类业务回归；轨迹 diff 用 `/v3/replay/compare`。
4. 通过后 `promote`；异常则把旧版本标回 stable（一键回滚）。

## 七、资源与限制

Milvus standalone 建议 ≥4GB 内存；首次拉镜像较慢。沙盒未实际拉起外部服务，
仅做了 compose 配置校验；离线演示请保持 `USE_EXTERNAL_INFRA=false`（默认），
四套适配器自动降级到进程内实现。
