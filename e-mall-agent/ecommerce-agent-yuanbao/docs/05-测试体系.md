## 二、关键用例写法（为什么这么测）

- **间接注入**：不测「模型会不会听话」，测「sanitize 是否去隐藏文本 + wrap 是否标 untrusted + 高危是否 refuse」。
  这是可规则判定的东西，总纲 7.4 明确说别用 LLM judge。
- **ACL**：断言 `visible == 1` 且 `milvus_expr` 下推到检索前，而不是召回后再丢。
- **错误分类**：429/timeout 可重试，422/403/quota 不可重试；断言 `suggested_action` 是「可操作」的。
- **pass^k**：故意构造 flaky runner，验证 `pass@k=0.5` 但 `pass^k=0`，把 C#9 固化成回归。
- **确定性重放**：录制轨迹 → 无 override 重放 digest 一致 → 第 1 步 override 后 digest 变化且 `time_travel_from=1`。
- **成本**：budget 极小的一次 charge 必须 `action=terminate`，防死循环烧钱。
