# 集成测试用例清单

| 层 | 用例 | 涉及组件 | 通过标准 |
|---|---|---|---|
| I01 | FastAPI + MCP stdio 子进程真实工具调用 | Python / FastMCP | ToolNode 执行，ToolMessage 回填 |
| I02 | MySQL 会话状态持久化 | MySQL / SQLAlchemy | 重启后 thread 状态可读 |
| I03 | Redis 会话 KV + TTL + 限流 | Redis | 过期自动失效 |
| I04 | RabbitMQ 三类事件 | RabbitMQ topic | longtask/audit/ragindex 各自消费 |
| I05 | Milvus 检索前 ACL 下推 | Milvus | expr 生效，无跨租户召回 |
| I06 | 文档更新 → 增量索引 → 缓存失效 | Milvus + Redis | 只 upsert diff，旧答案失效 |
| I07 | 双后端同契约 | Python + Java | check_contract.py PASS |
| I08 | 前端切换后端 | Vue3 + nginx | VITE_BACKEND 切换后页面正常 |
| I09 | 模型 fallback | DeepSeek→Qwen→Ollama | 如实标注生效来源 |
| I10 | HITL 超时扫描 | 定时任务 | 超时单默认拒绝 |
| I11 | 轨迹落盘 + 确定性重放 | MySQL traces | digest 一致 |
| I12 | CI 三重门禁 | GitHub Actions | 成功率/成本/P95 全过 |
| I13 | 评测集回归 | Golden Case + pass^k | 0 个 bad case |
| I14 | 安全红队集 | 8 条注入 | block_rate ≥ 0.8 |

> I01/I07/I13/I14 在离线沙盒即可跑；I02–I06、I08–I12 需 `docker compose up -d` 后在本地执行。
