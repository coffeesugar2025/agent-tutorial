# 差旅与费用报销制度

> 文档编号：HR-EXPENSE-2025 ｜ 版本：2025.1 ｜ 生效日期：2025-01-01 ｜ 适用对象：全体正式员工

## 1. 差旅审批

- 出差前须在 OA 提交《出差申请》，注明目的地、起止时间、事由与预算。
- 国内出差由直属主管审批；出境出差需部门负责人与财务负责人审批。
- 未审批产生的差旅费用，原则上不予报销。

## 2. 住宿标准

| 城市级别 | 每晚上限（元） |
| --- | --- |
| 一线城市（北京、上海、广州、深圳） | 600 |
| 新一线 / 省会城市 | 450 |
| 其他城市 | 350 |

- 超标部分由个人承担，特殊情况需提前审批。
- 同性同事同行原则上合住，按标准间报销。

## 3. 交通标准

- 飞机：经济舱；单程飞行超过 4 小时且职级 P6 及以上可乘坐超级经济舱。
- 高铁：二等座；职级 M2 及以上可乘坐一等座。
- 市内交通：优先公共交通，因公打车需在报销单注明事由。

## 4. 餐费与招待

- 出差餐费按每天 100 元包干，不再单独报销。
- 客户招待须提前申请，注明客户单位、人数、事由；人均不超过 300 元。
- 烟酒、娱乐场所消费不予报销。

## 5. 报销时限与材料

1. 费用发生后 **30 个自然日** 内提交报销，逾期需部门负责人特批。
2. 发票抬头必须为公司全称，税号正确；电子发票需上传原件。
3. 报销单需关联出差申请，交通、住宿票据齐全。
4. 财务在 5 个工作日内完成审核，审核通过后随下一个工资周期发放。

## 6. 违规处理

虚报、重复报销、购买发票等行为属于严重违纪，公司有权解除劳动合同并追究法律责任。

## 7. 附则

本制度自 2025 年 1 月 1 日起执行，由财务部与人力资源部共同解释。
