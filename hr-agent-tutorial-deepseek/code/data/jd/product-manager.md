# 高级产品经理（P6）· 招聘 JD

**部门**：产品部 ｜ **工作地点**：北京 ｜ **汇报对象**：产品总监 ｜ **编制**：1 人

## 岗位职责

1. 负责 HR Agent 产品的需求分析与路线图规划，覆盖招聘、员工服务、绩效等场景。
2. 深入客户现场调研，把模糊的业务诉求拆解为可执行的任务、状态机与验收标准。
3. 与算法、后端、前端协作，推动 RAG、工具调用、人工审批等能力落地。
4. 建立产品指标：任务完成率、人工接管率、用户满意度、单次服务成本。

## 任职要求

- 5 年以上 B 端产品经验，有 HR SaaS、OA、CRM 经验优先。
- 能独立完成需求文档、原型、验收用例，具备数据分析能力。
- 理解 LLM 应用的基本原理与边界，能与算法同学对齐评测口径。
- 优秀的跨团队沟通能力，能在不确定环境中推进项目。

## 面试评估维度

- 业务抽象（35%）：能否把场景拆成角色、流程、数据、异常。
- 产品设计（30%）：方案完整性与可落地性。
- 数据与评测（20%）：如何定义成功、如何验证。
- 协作与表达（15%）。

P6：30k–45k / 月，16 薪。
