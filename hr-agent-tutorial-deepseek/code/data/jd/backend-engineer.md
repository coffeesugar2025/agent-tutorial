# 后端工程师（P5）· 招聘 JD

**部门**：技术部 ｜ **工作地点**：上海 ｜ **汇报对象**：技术总监 ｜ **编制**：1 人

## 岗位职责

1. 负责 HR SaaS 产品后端服务的设计、开发与维护，保障接口稳定性与性能。
2. 参与 Agent 平台的服务化建设，包括工具网关、审批流、审计日志。
3. 与产品、前端、算法协作，完成需求评审、接口设计与联调。
4. 编写单元测试与技术文档，参与线上问题排查与复盘。

## 任职要求

- 本科及以上学历，计算机相关专业，3 年以上后端开发经验。
- 熟练掌握 Python，熟悉 FastAPI / Django 等至少一种 Web 框架。
- 熟悉 MySQL、Redis，理解索引、事务与缓存一致性。
- 有良好的工程习惯：Git、Code Review、测试、CI/CD。
- 有 LLM 应用或 Agent 项目经验者优先。

## 面试评估维度

- 编码能力（40%）：数据结构、边界条件、代码可读性。
- 系统设计（30%）：高并发、幂等、可观测性。
- 业务理解（20%）：能否把 HR 业务规则转成接口与状态机。
- 沟通协作（10%）：需求澄清与跨团队推进。

## 薪资带宽

P5：25k–38k / 月，16 薪。
