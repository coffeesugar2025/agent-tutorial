# 18 · Vue3 前端工作台：SSE 把"Agent 在想什么"显示出来

## 18.1 本章目标

1. 用 `astream_events(version="v2")` 把 Agent 的内部动作变成事件流；
2. 用一个 stdlib 的 HTTP 服务把事件以 SSE 推送出去；
3. 用 Vue3（单文件 + importmap）渲染时间线，不用装 Node；
4. 提供一个无浏览器也能验收的 `client.py`。

跑法：

```powershell
# 终端 A
.\.venv\Scripts\python.exe ch18_vue_frontend\server.py
# 终端 B
.\.venv\Scripts\python.exe ch18_vue_frontend\client.py
# 浏览器（可选）
http://127.0.0.1:8765/
```

## 18.2 为什么是 SSE，不是干脆等

Agent 一次回答可能要 3–8 秒，中间调 2 个工具。用户面对的如果是白屏，体感是"卡死了"。

SSE 的价值不是"打字机效果"，是**把过程可视化**：

```
start → thinking → get_leave_balance → tool_end → thinking → get_headcount → tool_end
      → thinking → answer → done
```

用户看到"正在查年假余额""正在查在职人数"，就知道系统没死、也知道它凭什么这么说。

## 18.3 关键坑：同步 `stream_events` 不支持 v2

```python
agent.stream_events(input, version="v2")
# NotImplementedError: Use astream_events() for v1/v2
```

1.x 里**只有 async 版本**支持 v2 事件。而 `server.py` 是同步的 `ThreadingHTTPServer`，所以要包一层：

```python
def stream_events(message):
    async def gen():
        async for ev in agent.astream_events({"messages": [{"role": "user", "content": message}]},
                                             version="v2"):
            yield ev
    loop = asyncio.new_event_loop()
    try:
        for ev in _iterate(loop, gen()):        # 把 async 生成器在同步循环里消费
            ...
```

## 18.4 事件 → 帧

只挑三种事件，其余丢掉（事件类型有几十种，前端不该全知道）：

| `event` | 用途 |
|---|---|
| `on_chat_model_stream` | 模型的 token（打字机效果） |
| `on_tool_start` | 工具开始（显示"正在查…"） |
| `on_tool_end` | 工具结束（显示耗时） |

SSE 帧格式（必须严格，浏览器 EventSource 才认）：

```
event: tool_start
data: {"name": "get_leave_balance", "args": {...}}

event: answer
data: {"text": "结论：张伟 2026 年年假剩 7 天；技术中心在职 3 人。"}
```

## 18.5 实测：客户端看到的完整事件链

```
[event] start
[event] thinking  ""
[event] tool_start get_leave_balance {'emp_id': 'E1001', 'year': 2026}
[event] tool_end   get_leave_balance 剩余 7 天
[event] thinking  ""
[event] tool_start get_headcount {'dept': '技术中心'}
[event] tool_end   get_headcount 在职 3 人
[event] thinking  ""
[event] answer    结论：张伟 2026 年年假剩 7 天；技术中心在职 3 人。
[event] done
```

★ 用 `client.py` 验收的好处：**不依赖浏览器、不依赖 CDN**，CI 里也能跑。

## 18.6 Vue3 单文件页面

```html
<script type="importmap">
{"imports": {"vue": "https://unpkg.com/vue@3/dist/vue.esm-browser.prod.js"}}
</script>
<script type="module">
import { createApp, ref, onMounted } from 'vue';
createApp({
  setup() {
    const items = ref([]);
    onMounted(() => {
      const es = new EventSource('/events?q=' + encodeURIComponent(q));
      es.addEventListener('tool_start', e => items.value.push({kind:'tool', text: ...}));
      es.addEventListener('answer',     e => items.value.push({kind:'answer', text: ...}));
      es.addEventListener('done',       () => es.close());
    });
    return { items };
  }
}).mount('#app');
</script>
```

时间线上不同 kind 用不同颜色/图标：thinking 灰、tool 蓝、answer 绿。**这是 Agent 前端和普通聊天前端最大的区别——它有一条"可读的执行轨迹"。**

注意：页面依赖 unpkg CDN，**离线环境不渲染**。所以验收以 `client.py` 为准（这也是本章给两个入口的原因）。

## 18.7 生产上要补什么

| 教学版 | 生产版 |
|---|---|
| `ThreadingHTTPServer` | FastAPI + `sse-starlette` |
| 无鉴权 | 登录态 + 会话隔离（`thread_id` 按用户） |
| 单轮问答 | 多轮（把 `thread_id` 交给 checkpointer，第 07/14 章） |
| 无断线处理 | 心跳（15s 一次 `: ping`）+ 断线重连 `Last-Event-ID` |
| 前端直连 | 网关后面的 SSE 要关缓冲（nginx `proxy_buffering off`） |

**最容易踩的生产坑**：nginx 默认缓冲 SSE，你本地好好的，上线后一次性吐出来。必须 `proxy_buffering: off` + `X-Accel-Buffering: no`。

## 18.8 常见坑

1. **同步 `stream_events(version="v2")`** —— 不支持（见 18.3）。
2. **`event:` / `data:` 帧格式不对**（少了空行），浏览器不触发。
3. **忘了 `done` 后 `es.close()`**：连接不释放，服务端线程越积越多。
4. **把全部事件都转发**：前端处理不过来，日志也爆炸。只转发用户需要看的。
5. **中文乱码**：响应头必须有 `charset=utf-8`。
6. **跨域**：本地 8765 → 前端 5173 时，要加 CORS 头。
