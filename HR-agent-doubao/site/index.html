HR 场景 Agent 工程教程（LangChain / LangGraph 全程实战）

面向零基础，Python 3.12 + Vue 3，21 章正文 + 19 个可独立运行的小 demo。 全书不用"伪代码"：每一章的代码都用真实的 LangChain 1.5 / LangGraph 原语实现，可以直接搬进项目。 没有 API Key 也能跑完（内置 ScriptedChatModel 假模型，流程、工具循环、结构化输出都是真实发生的）。

这本书想解决什么问题

市面上的 Agent 教程大多停在"能跑个 demo"。但 JD 里那句"不是跑 demo，是上生产干活"，翻译过来是六个字：

接系统、调工具、读知识、跑流程、出结果、可验收。

所以全书按这个顺序组织，且每一步都落在具体的 LangChain / LangGraph 原语上：

阶段你学完能干什么章节主要原语
一、能对话让模型稳定输出结构化数据00–02ChatPromptTemplate、LCEL、with_structured_output
二、能干活自己跑循环、定义工具、按计划执行03–06create_agent、StateGraph、ToolNode、Send
三、有记忆上下文不爆、跨会话记得住、能删干净07–08RunnableWithMessageHistory、InMemoryVectorStore、trim_messages
四、懂知识从接向量库到混合检索、版本治理、Text2SQL/图09–11RecursiveCharacterTextSplitter、BM25Retriever、EnsembleRetriever、SQLDatabase
五、能协作工具标准化、多智能体、人在环12–14MCP 适配、Supervisor、interrupt()/Command(resume=)
六、敢上线重试幂等降级、长任务、Trace 与评测15–17with_retry、with_fallbacks、BaseCallbackHandler
七、交付产品Vue3 工作台、模型工程、求职落点18–20astream_events(v2)、init_chat_model

Get-ChildItem -Directory -Filter "ch*" | ForEach-Object {
  if ($_.Name -eq "_legacy" -or $_.Name -eq "ch18_vue_frontend") { return }

  if (Test-Path $m) { Write-Host "== $($_.Name)"; & ".\.venv\Scripts\python.exe" $m }
}

两个特殊章节：

  • ch12（MCP）：默认走本地 Mock 服务演示完整协议往返；ch12_mcp\server.py 是可选的真 MCP 服务端（需 pip install mcp langchain-mcp-adapters）。
  • ch18（前端）：server.py + client.py 可在无浏览器环境验收；index.html 是单文件 Vue3（首次需联网拉 unpkg）。

接真模型：复制 demos\.env.example 为 .env，填 LLM_BASE_URL / LLM_MODEL / LLM_API_KEY（默认指向 DeepSeek）。 不填则每个 demo 首行提示"已切换到 ScriptedChatModel"，这不是报错。

每章怎么读

统一骨架：目标 → 对应的 LangChain 原语 → 代码讲解 → 实测输出 → 常见坑 → 自检清单 → 练习。

"实测输出"都是真跑出来的，包括踩过的坑（比如 InMemoryVectorStore 的 filter 要传函数、EnsembleRetriever 搬去了 langchain-classic、同步 stream_events 不支持 v2）。这些是本章最值钱的部分——它们能替你省下几个小时。

没验过的部分（避免误导你）：

  • 没有用真实模型跑过：仓库无 .env，输出全部来自剧本假模型。接真模型时自行确认服务商支持 tools 字段。
  • mcp / langchain-mcp-adapters 未安装：ch12 走本地 Mock 服务，真 MCP 握手以注释形式给出。
  • 无 GPU：ch19 的 LoRA / vLLM 只给配置与命令，没真训练；vLLM 需 Linux + CUDA。
  • ch18 页面依赖 unpkg CDN：离线环境页面不渲染，验收以 client.py 为准。
